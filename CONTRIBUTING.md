# Contributing to Awesome AI Video Generators

Thank you for your interest in contributing! This list aims to be a high-quality, community-maintained resource for AI video generation tools and research.

## Guidelines

### Adding a New Tool or Resource

1. **Fork** this repository
2. **Add your entry** in the appropriate category
3. **Submit a pull request** with a clear description

### Requirements for New Entries

- The tool must be **publicly accessible** (not private beta with no way to request access)
- Include a **brief, factual description** of what makes it unique
- Provide a **working link** to the official website or repository
- Do not use promotional language — describe features, not marketing claims

### Formatting

- Follow the existing table format for tool entries
- Keep descriptions concise (under 15 words for table entries)
- Use proper markdown formatting
- Alphabetical order within each category is preferred but not required

### Quality Standards

- No duplicate entries
- No affiliate links
- No tools that have been discontinued or are no longer maintained
- Research papers should link to arXiv or the official publication page

### What We Accept

- AI video generation platforms and tools
- Open source video generation models
- Relevant research papers and technical reports
- Educational resources and tutorials
- Benchmarks and comparison data

### What We Don't Accept

- Generic video editing tools without AI capabilities
- Tools with no public information available
- Spam or purely promotional content

## Reporting Issues

If you find a broken link, outdated information, or have suggestions for improvement, please [open an issue](../../issues).

## Code of Conduct

Be respectful and constructive. We're all here to build a useful resource for the community.
